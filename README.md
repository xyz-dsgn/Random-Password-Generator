# Random-Password-Generator
Программа для генерации случайных паролей

## Описание программы 
Графическое приложение на Python для генерации случайных паролей с настраиваемыми параметрами. Приложение позволяет генерировать пароли различной длины, выбирать типы используемых символов, сохранять историю сгенерированных паролей в JSON и управлять ею.
## Требования для запуска 
Что нужно установить на компьютер: 
- Python 3.10 или выше 
- Библиотеки: `pip install tkinter`
## Как запустить 
```bash 
git clone https://github.com/xyz-dsgn/Random-Password-Generator
cd Random-Password-Generator
python main.py
```
## Как пользоваться
Настройка параметров пароля
- Длина пароля: перемещайте ползунок для выбора длины от 4 до 32 символов
- Заглавные буквы (A-Z): отметьте для включения заглавных букв
- Строчные буквы (a-z): отметьте для включения строчных букв
- Цифры (0-9): отметьте для включения цифр
- Специальные символы: отметьте для включения символов !@#$%^&*()_+-=[]{}|;:,.<>?

Генерация пароля
- Нажмите кнопку "Сгенерировать пароль" для создания нового пароля
- Сгенерированный пароль отобразится в верхнем поле
- Нажмите "Копировать" для копирования пароля в буфер обмена

Управление историей
- Все сгенерированные пароли автоматически сохраняются в историю
- История отображается в таблице с указанием даты, пароля, длины и использованных символов
- Очистить историю: удаляет все сохраненные пароли
- Сохранить историю: сохраняет текущую историю в JSON файл
- Загрузить историю: загружает историю из JSON файла
## Пример работы 
1. Запуск программы — открывается окно с настройками и историей.
2. Настройка параметров:
- Длина пароля: 16
- Выбраны: Заглавные буквы, Строчные буквы, Цифры
- Спецсимволы: Выключены
3. Генерация пароля:
- Нажать Сгенерировать пароль
- Появляется пароль: Kx7mPq9rTv2wLc4n
- Нажать Копировать — пароль скопирован
4. Просмотр истории:
- В таблице появляется запись:
- Дата: 2026-05-04 15:30:22
- Пароль: Kx7mPq9rTv2wLc4n
- Длина: 16
- Символы: a-z, A-Z, 0-9
5. Сохранение истории:
Нажать Сохранить историю — данные сохраняются в password_history.json
